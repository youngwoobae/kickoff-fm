# 시뮬레이션 배치 검증 (엔진 0.3.0)

- 대상: 기획서 v2 8.1 보정 목표(2026-09-27 갱신), 아키텍처 문서 12.1 `sim:batch` 시나리오
- 실행: `npm run sim:batch -- --n 2000 --cap 0.5 --json sim-out/report-0.5.json --strict` (seed 20260926) → **ALL PASS, exit 0**
- 규모: 시나리오당 2,000경기. COUNTER_SPREAD 는 5×5 조합 × 1,000경기 = 25,000경기, OVR_DIFF_10_COUNTER 는 전술 켬/끔 각 2,000경기, RULE_ISOLATION 은 규칙 11개 × 1,000경기 + 2,000경기. 전체 약 5만 경기, 54초
- 합성 팀: `generateSquad` 로 주전 평균 OVR 을 맞춘 22인 스쿼드 30개를 돌려 쓴다(20경기마다 교체). 전술 숙련도 100, 짝수 경기는 X 홈·홀수 경기는 Y 홈
- 아래 수치는 모두 실제 출력이다. 상한 0.25 / 0.35 비교는 `--cap 0.25|0.35 --scenario COUNTER_SPREAD,OVR_DIFF_10_COUNTER` 로 따로 돌렸다
- 0.3.0 은 2026-09-27 사용자 결정 **"동일 전력에서 전술 영향(최선−최악 카운터 승률 차)을 15~30%p 로 올린다"** 를 반영한 재보정이다

## 5. (c) 전력 차 vs 전술 효과: "전술만으로 결과가 결정되지 않는다"

| 비교 (cap 0.5) | 강팀 승 / 무 / 약팀 승 (%) |
|---|---|
| 전력 10점 차 (65 vs 55), 둘 다 균형 | 64.3 / 19.9 / 15.8 |
| 같은 대진, 약팀이 균형 상대 최선 카운터(점유 4-3-3) | 54.0 / 22.1 / 23.8 |
| 같은 대진, 전술 효과 끔(`tacticsEnabled=false`) | 65.2 / — / 15.3 |
| 전력 25점 차 (72.5 vs 47.5) | 92.1 / 5.6 / 2.3 |

- 전력 10점 차의 우위(전술 끔, 강팀 승 − 약팀 승) = 49.9%p. 동일 전력 전술 최대 효과(최선−최악 17.4%p)의 **2.86배**다.
- 약팀이 최선 카운터를 써도 강팀 승률은 65.2 → 54.0% 로 11%p 내려갈 뿐이다. 강팀 승(54.0)이 약팀 승(23.8)보다 30%p 높다. 전력 25점 차는 어떤 전술로도 뒤집히지 않는다(92.1%).
- 결론: 전술은 이제 "보이는 차이"(동일 전력 17%p, 전력 10점 차 대진의 약팀 승률을 15 → 24% 로)를 만든다. 동시에 전력 차를 뒤집지는 못한다.

## 7. 남은 위험

- 교차검증 승률 차 17.4%p 는 목표 하한(15)과 2.4%p 차이다. 교차검증 절반 표본의 표준오차는 약 2~3%p 라 시드에 따라 15 근처로 내려갈 수 있다. Vitest 게이트는 고정 시드(20260926, n=1000)로 검사한다.
- R7(중원 수적 우위)은 포메이션만으로 항상 켜진다. 단독 P95 0.450 으로 새 상한(0.5)에 가장 가깝다. 균형 4-4-2(중앙 MF 2)가 거의 모든 상대에게 불리한 주 원인이다.
- 봇 감독 AI 의 슬롯 선택 휴리스틱(`domain/ai/matchup.ts`)은 새 R2 역효과·R5 이득을 반영했다. 다만 휴리스틱일 뿐 엔진 결과로 검증하지는 않았다.
- 전술 영향이 커져 실제 리그 한 시즌의 결과가 봇 성향 조합에 더 민감해졌다. 사람 팀의 상대 분석·카운터 선택 가치가 커진 것이라 의도한 방향이지만, Q-A 설문으로 체감을 확인해야 한다.

## 8. 재현 방법

```
npm run sim:batch -- --n 2000 --strict                      # 전 시나리오, cap 0.5 (약 55초, exit 0)
npm run sim:batch -- --n 2000 --cap 0.35 --scenario COUNTER_SPREAD,OVR_DIFF_10_COUNTER
npm run sim:batch -- --build-values --n 20000               # VALUE 테이블 재생성
```

Vitest(`tests/engine/engine.test.ts`) 게이트: BASELINE 1,000경기(득점·무승부·슈팅), OVR_DIFF_25 1,000경기, RULE_ISOLATION(규칙당 200경기, P95 ≤ 0.5 / 합 ≤ 0.8), **COUNTER_SPREAD 12,500경기(15~30%p, 60~70%)**, **OVR_DIFF_10_COUNTER(50~60%, 강팀 우세, 전력 우위 ≥ 전술 효과)**.
