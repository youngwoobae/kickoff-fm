# 시뮬레이션 배치 검증 (엔진 0.5.0)

- 대상: 엔진 0.5.0 전술 영향 재보정 (기준: 748084c = 엔진 0.4.0, cap 0.5). 기획서 v2 8.1 보정 목표, `docs/실축구_전술설계.md`
- 실행: `npm run sim:batch -- --n 2000 --strict --json sim-out/report-0.5.0.json` (seed 20260926, cap 0.7 = 기본값) → **FAIL (exit 1)**, 목표 80개 중 **76개 PASS**. 미달 4개(포메이션 공평성 3, 역할 서명 방향 1)는 5장
- 교차 확인: `npm run sim:batch -- --n 2000 --seed 777 --scenario STYLE_MATRIX,OVR_DIFF_10_COUNTER` (게이트와 다른 시드)
- 아래 수치는 모두 위 실행의 실제 출력이다. "0.4.0" 열은 이 문서 이전 판(748084c 에서 같은 명령, cap 0.5)의 값이다

## 1. 목표와 0.5.0 에서 바꾼 판정 기준

우선순위 (위가 절대 우선):

1. 동일 전력 최선 − 최악 교차검증 승률 차 **15 ~ 30%p** (게이트 시드와 다른 시드 1개, 두 시드 모두). 한 스타일의 일방적 약세가 아니라 상성에서 나와야 한다
2. 절대 우위 스타일 없음(스타일 평균 승 − 패 ≤ +8%p), 모든 스타일이 최소 1개 상대에게 우위(≥ +6%p), 설계 9×9 부호 일치
3. 전력 25점 차 강팀 ≥ 85%, 전력 10점 차 우위 ÷ 전술 최대 효과 ≥ 1.0
4. 리그 현실 통계(LEAGUE_REALISM, REAL_HOME, BASELINE) 최대한 유지
