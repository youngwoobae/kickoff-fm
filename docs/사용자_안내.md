# 킥오프 FM 플레이 안내

인터넷 없이 하는 축구 감독 게임이에요. 무명 구단을 맡아 매일 경기 플랜을 짜고, 5부 루키 리그에서 1부 프리미어 디비전 우승까지 올라가 보세요.

> 모든 기록은 **이 기기 안에만** 저장돼요. 서버·로그인·결제·광고가 없고, 어디로도 보내지 않아요. 그래서 기기를 바꾸거나 브라우저 데이터를 지우기 전에는 꼭 [백업](#세이브-백업과-기기-이동)해 주세요.

## 설치

처음 한 번은 인터넷이 필요해요. 설치하면 그다음부터는 비행기 모드에서도 열려요.

| 기기 | 방법 |
|---|---|
| Android (크롬) | 게임 주소를 열고 메뉴 ⋮ → **앱 설치**(또는 홈 화면에 추가) |
| iPhone·iPad (사파리) | 공유 버튼 → **홈 화면에 추가**. 설치하지 않으면 사파리가 저장 데이터를 지울 수 있어요 |
| PC (크롬·엣지) | 주소창 오른쪽 설치 아이콘 → **설치** |

새 버전이 나오면 "새 버전이 있어요" 배너가 떠요. **새로고침**을 누르면 저장을 끝낸 뒤 바뀌어요.

## 시작하기

1. 타이틀에서 빈 슬롯의 **새 게임** → 구단 이름, 시작 리그(루키 리그 = 기본, 디비전 2 = 도전) → **창단하고 시작**
2. 튜토리얼 6단계를 따라가요. 설정 ⚙ → **튜토리얼 다시 보기**로 언제든 다시 볼 수 있어요.

슬롯은 3개예요. 진행은 매일 자동 저장돼요.

## 하루 루틴

| 순서 | 할 일 | 위치 |
|---|---|---|
| 1 | 다음 상대와 "지금 마감되면 적용될 플랜" 확인 | 홈 |
| 2 | 바로 하려면 **추천 플랜 제출**, 직접 하려면 경기 플랜 편집 → **확정 제출** | 홈 / 전술 → 경기 플랜 |
| 3 | **다음 날로 넘기기** (남은 시즌을 한 번에: **시즌 끝까지**) | 홈 |
| 4 | 중계 보기, 리포트로 왜 이겼는지·졌는지 확인 | 경기 |
| 5 | 받은 편지함 확인 (✉) | 홈 |

플랜을 확정하지 않아도 경기는 해요. 기본 플랜 → 지난 경기 플랜 → 감독 추천 순으로 자동 적용되고, 부상·징계 선수는 자동으로 바뀌어요.

## 시즌과 승강

- 1시즌 = 28일: 26경기 + 상금(Day 27) + 정산(Day 28). 시즌이 끝나면 **새 시즌 시작**을 눌러요.
- 리그는 5단계, 각 14팀이에요: 프리미어 디비전 · 디비전 1 · 디비전 2 · 디비전 3 · 루키 리그.

| 경계 | 승격 / 강등 |
|---|---|
| 프리미어 ↔ 디비전 1 ↔ 디비전 2 | 2팀씩 |
| 디비전 2 ↔ 디비전 3 ↔ 루키 리그 | 3팀씩 |

- 순위표의 ▲▼ 표시가 승강 구역이에요. 승격하면 보너스, 강등되면 연봉 보조금이 나와요.
- 지난 시즌 기록과 트로피는 클럽 → **커리어**에서 봐요.

## 전술과 플랜 기초

| 용어 | 뜻 |
|---|---|
| 전술 슬롯 A/B | 구단의 팀 전술 두 벌(포메이션·스타일·팀 지시·선수 역할). 자주 쓸수록 숙련도가 올라가요 |
| 경기 플랜 | 그 경기에 쓸 시작 슬롯 + 선발·벤치 + 조건부 지시 |
| 스타일 카드 | 점유·역습·전방 압박 같은 9가지 스타일. 상대 스타일과 상성이 있어요 |
| 조건부 지시 | "60분에 지고 있으면 B 슬롯으로" 같은 경기 중 자동 변경(최대 3개). 경기 중 직접 개입은 없어요 |
| 자동 로테이션 | 컨디션 70 미만 선발을 벤치 선수로 바꿔 줘요 |

팁: 경기 전 상대 분석과 상성 힌트를 보고, 리포트의 "다음 경기 제안"을 참고하세요. 포메이션을 바꾸면 숙련도가 절반이 되니 자주 바꾸지 마세요.

## 이적·계약·유스·훈련

| 항목 | 언제 | 핵심 |
|---|---|---|
| 이적 창 | 중간 Day 11~15, 정규 Day 25 ~ 다음 시즌 Day 2 | 클럽 → **이적**. 입찰은 한 번, 다른 구단 입찰은 안 보여요(블라인드). 입찰 금액은 예약돼서 그만큼 못 써요 |
| 판매 | 이적 창 동안 | 선수 상세에서 판매 등록(최저가 지정) |
| 재계약 | Day 20~27 | 재계약 안 한 만료 선수는 시즌이 끝나면 FA로 떠나요. 이미 재계약한 선수는 다시 못 해요 |
| 방출 | 언제든 | 남은 연봉의 50%를 위약금으로 내요. 되돌릴 수 없고, 그 시즌엔 FA로 다시 못 데려와요 |
| 유스 | 시즌 시작 ~ Day 7 | 스쿼드 → **유스**에서 후보 중 최대 2명 승격. 안 정하면 자동으로 정해져요 |
| 훈련 포커스 | 언제든 | 균형·공격·수비·체력·전술 숙련·회복. 다음 주부터 적용 |
| 은퇴 | Day 20 예고 | 33세부터 은퇴할 수 있어요 |
| 경고 누적 | 시즌 중 | 5장이면 1경기 정지, 시즌이 바뀌면 초기화 |

**잔액이 마이너스**가 되면 입찰이 막히고, 3일 뒤 비주전 선수가 자동으로 팔려요. 재정 화면에서 지출 가능액을 확인하세요.

## 코치 프로필 (한 기기로 함께 하기)

친구·가족과 한 기기를 번갈아 쥐고 구단주와 코치로 운영할 수 있어요.

- 구단주 1명 + 코치 최대 5명. 클럽 → **코치실**에서 멤버를 추가하고, 상단 멤버 칩으로 차례를 바꿔요.
- 실행(플랜 확정·입찰·재계약·승인)은 구단주만 해요. 코치는 역할에 맞는 **제안**을 올리고 구단주가 승인·거절해요.

| 코치 역할 | 할 수 있는 제안 |
|---|---|
| 전술(TAC)·분석(ANL) | 플랜·전술 변경 |
| 스쿼드(SQD) | 플랜 변경, 재계약 |
| 스카우트(SCT) | 이적 입찰 |
| 재정(FIN) | 이적 입찰, 재계약 |

- 제안은 다음 날 처리 때 만료돼요. 새로 들어온 코치는 첫날 당일 플랜을 볼 수 없어요.
- **구단주 PIN**(4자리)을 걸면 구단주로 바꿀 때 PIN을 물어요. 차례 전환 방지용이지 보안 잠금은 아니에요.

## 세이브 백업과 기기 이동

| 하고 싶은 것 | 방법 |
|---|---|
| 백업 | 설정 ⚙ → **이 세이브 내보내기**, 또는 타이틀에서 슬롯 **내보내기** → JSON 파일이 저장돼요 |
| 다른 기기로 옮기기 | 새 기기에 설치 → 타이틀에서 슬롯 **가져오기** → 백업 파일 선택 |
| 지우기 | 타이틀에서 슬롯 **삭제** (되돌릴 수 없어요) |

- 시즌이 끝날 때마다 백업을 권해요.
- 같은 세이브를 두 창(앱과 브라우저 탭 등)에서 열면 나중에 연 창만 남고 먼저 연 창은 닫혀요. 진행이 덮어써지지 않게 하려는 거예요.
- 슬롯에 "⚠ 손상됨"이 뜨면 먼저 내보내기로 보관한 뒤 삭제하고 다시 시작해 주세요.

## 자주 묻는 질문

**인터넷이 꼭 필요한가요?** 처음 열 때만요. 설치 뒤에는 오프라인으로 돼요.

**다른 사람과 온라인으로 대결할 수 있나요?** 아직은 안 돼요. 한 기기에서 코치 프로필로 함께 할 수 있어요.

**앱을 지우면 세이브도 사라지나요?** 네. 기기에만 저장되니 지우기 전에 내보내기 해 주세요.

**PIN을 잊었어요.** 세이브를 내보낸 JSON 파일에서 `ownerPin` 항목을 지우고 다시 가져오면 돼요.

**글자가 작거나 화면이 움직이는 게 불편해요.** 설정에서 글자 크기(크게·아주 크게)와 모션 줄이기를 켜요. 테마(라이트·다크)도 바꿀 수 있어요.

**중계가 길어요.** 설정에서 기본 재생 속도를 바꾸거나, 경기 화면을 꺼서 텍스트 중계만 볼 수 있어요.

**실제 선수·구단이 나오나요?** 아니요. 모든 선수와 구단은 가상이에요.
