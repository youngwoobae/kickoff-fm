## 0. 설계 원칙 (유지할 것과 바꿀 것)

**유지 (엔진 골격)**
1. 구역 전진 경합 체인(Z0→Z1→Z2)과 결정 지점 DP1~DP8.
2. 전술은 **logit 가산치로만** 개입한다. `tac_DP = clamp(Σ r'_i, −cap, +cap)`, 기본 cap 0.5. 확률을 직접 바꾸거나 경합을 건너뛰는 규칙은 없다.
3. 긍정 가산치에만 숙련도 계수(famCoef 0.5~1.0). 기여도 분해(8.8) 합 보존.
4. 게임 목표: 동일 전력 최선−최악 카운터 승률 차 15~30%p, 전력 25점 차 강팀 ≥ 85%, 전력 10점 차 우위 ÷ 전술 최대 효과 ≥ 1.0.
5. `TeamInstructions`(6 슬라이더 + 토글 2) 계약은 **바꾸지 않는다**. 스타일은 "슬라이더 묶음 + 권장 포메이션 + 권장 역할"이다.

**바꿀 것**
1. 규칙 크기를 **팀 유닛 평균만이 아니라 특정 선수 매치업**(가장 빠른 러너 vs 가장 느린 CB 등)으로 정한다 → "전술 + 선수 적합"이 함께 작동.
2. 포메이션 고정값 `centralMidfielders` 로 항상 켜지던 R7 을 **역할 기반 "유효 인원"** 계산으로 바꾼다 → 4-4-2 상시 불리 문제 해결(2.4).
3. 역할마다 **형태값(ROLE_SHAPE)**: 중앙·측면·하프스페이스 점유, 러너 여부 등을 두어 규칙 조건에 쓴다.
4. 경기 구조(추가시간, 경기 상황, 홈 이점)와 통계 출력(유효슈팅, 코너, 경고)을 실제 리그 분포에 맞춘다. 이 부분은 **전술 가산치가 아닌 구조 보정**이다(cap 밖, 양 팀 대칭 또는 홈/상황 기반).

## 1. 실제 전술 스타일 카탈로그 (9종 = 실제 스타일 8 + 균형)

### 1.1 요약표

슬라이더 순서: 성향 / 압박 / 라인 / 폭 / 템포 / 패스(직선성). 토글: 역습(C), 오프사이드 트랩(T).

| ID | 이름 | 실제 모델 (참고) | 권장 포메이션 | 성향 | 압박 | 라인 | 폭 | 템포 | 패스 | C | T | 체력 비용 |
|---|---|---|---|---|---|---|---|---|---|---|---|---|
| BALANCED | 균형 | 일반적 4-2-3-1 | 4-2-3-1 | 0 | 0 | 0 | 0 | 0 | 0 | – | – | 기본 (30) |
| GEGENPRESS | 게겐프레싱 | 클롭 도르트문트·리버풀 | 4-3-3 | +1 | +2 | +1 | 0 | +2 | +1 | ON | – | 매우 높음 (+8) |
| POSITIONAL | 포지셔널 플레이(티키타카) | 과르디올라 바르사·맨시티 | 4-3-3 (인버티드 FB → 3-2-5) | +1 | +1 | +1 | +1 | −1 | −2 | – | – | 보통 (+3) |
| LOW_BLOCK | 로우 블록(카테나치오) | 시메오네, 무리뉴 | 5-3-2 / 5-4-1 | −1 | −1 | −2 | −1 | −1 | +1 | ON | – | 낮음 (−2) |
| MID_BLOCK_COUNTER | 미드 블록 역습 | 안첼로티 레알, 라니에리 레스터 | 4-4-2 | −1 | 0 | 0 | 0 | +1 | +1 | ON | – | 보통 (+1) |
| DIRECT | 다이렉트 롱볼·타깃맨 | 다이치 번리, 앨러다이스 | 4-4-2 | 0 | 0 | 0 | +1 | +1 | +2 | – | – | 보통 (+1) |
| WING_PLAY | 윙 플레이·크로스 | 하인케스 바이에른(로벤·리베리), 전통 잉글랜드 4-4-2 | 4-4-2 / 4-2-3-1 | +1 | 0 | 0 | +2 | 0 | 0 | – | – | 보통 (+2) |
| HIGH_LINE | 하이 라인 오프사이드 트랩 | 사키 밀란, 플릭 바르사(24-25) | 4-4-2 / 4-3-3 | 0 | +1 | +2 | 0 | 0 | 0 | – | ON | 높음 (+4) |
| WINGBACK_3 | 3백 윙백 시스템 | 콘테 첼시·인테르 | 3-4-3 / 3-5-2 | 0 | +1 | 0 | +2 | 0 | 0 | ON | – | 높음(윙백) (+3, WB +3) |

체력 비용 = 경기 전체 소모 30 대비 추가분 `[PH]`. 공식: `30 + 3 × max(press, 0) + 1 × max(tempo, 0) − 1 × max(−press, 0) − 1 × max(−line, 0) + 역할 추가`. 기존 `CONDITION.pressDrainPerStep` 3 을 유지하고 템포·낮은 블록 항만 더한다.

기존 프리셋 ID 는 **그대로 두고 라벨·값만 바꾼다**(세이브 영향 없음, 프리셋은 지시값만 저장): `POSSESSION → POSITIONAL`, `COUNTER → MID_BLOCK_COUNTER`, `HIGH_PRESS → GEGENPRESS`, `LOW_BLOCK` 유지. 코드상 ID 는 기존 문자열을 유지하고 새 ID `DIRECT`, `WING_PLAY`, `HIGH_LINE`, `WINGBACK_3` 만 추가하는 방식을 권장한다(6.2 계약 참고). 이 문서는 읽기 쉽게 새 이름을 쓴다.

### 1.2 스타일 상세

각 스타일: **원리**(실제 축구) → **요구 선수 특성**(유닛·역할, 미달 시 적합도 배수) → **강점**(발동 규칙) → **약점**(당하는 규칙) → **권장 역할**.

#### (1) BALANCED 균형
- 원리: 특정 국면에 치우치지 않는 4-2-3-1. 더블 피벗이 하프스페이스·역습을 모두 막는다.
- 요구: 없음. 적합도 항상 100%.
- 강점: 큰 약점이 없다. 더블 피벗(R11 방어), 3 중앙(R7 방어). 직선적 팀(MID_BLOCK_COUNTER, DIRECT)에 약우위.
- 약점: 스스로 켜는 이득 규칙이 거의 없다. 압박(R1)·점유(R7/R11)에 약열세.
- 권장 역할: GK 전통, CB 스토퍼+볼플레잉, FB 수비형+공격형, DM 앵커+박스투박스, AM 공격형 플레이메이커, W 윙어+인사이드 포워드, ST 어드밴스드 포워드.

#### (2) GEGENPRESS 게겐프레싱
- 원리: 공을 잃은 직후 5~8초 안에 되찾는 역압박. 높은 위치의 탈취가 곧 최고의 찬스메이커다. 짧은 빌드업을 하는 상대를 질식시키지만, 압박을 한 번에 넘기는 롱볼과 뒷공간에 약하다. 후반 체력이 떨어진다.
- 요구: PRS ≥ 65(활동량·속도·태클), 수비 라인 PACE_D ≥ 60, 선수 체력 능력치 평균 ≥ 13. 미달 시 R1 × PRS/65 (기존 pressFit), 체력은 그대로 소모.
- 강점: R1(DP1·DP8 상대 빌드업 −, DP6 역압박 전환 +), 짧게 빌드업하는 POSITIONAL(BU 가 PRS 보다 낮을 때)·BALANCED·WINGBACK_3·WING_PLAY 에 우위.
- 약점: R2(뒷공간), R13(타깃맨 롱볼 우회), LINE_FIT, 체력(후반 xG 비중 하락). DIRECT 에 강열세, MID_BLOCK_COUNTER·LOW_BLOCK 에 열세.
- 권장 역할: ST 프레싱 포워드, CM 박스투박스×2 또는 메짤라, DM 볼 위닝, W 인사이드 포워드, GK 스위퍼, CB 커버.

#### (3) POSITIONAL 포지셔널 플레이 (티키타카)
- 원리: 5레인 점유. 인버티드 FB 가 중원으로 들어가 3-2 빌드업, 하프스페이스에 인사이드 포워드·메짤라를 두어 중앙 수적 우위를 만든다. 공을 오래 가져 상대를 지치게 하지만, 깊이 내려앉은 블록에서 박스 안 공간을 못 찾는다. 공을 잃으면 높은 라인 뒤가 빈다.
- 요구: BU ≥ 65, CTRL ≥ 65 (패스·침착·시야). 미달 시 R7·R11 이득 × BU/65, DP8 리셋 × BU/60 (기존 shortPassFit).
- 강점: R7(중앙 유효 인원 우위), R11(하프스페이스 과부하), DP8 리셋 ↑(점유율 60~68%). BALANCED·WING_PLAY·DIRECT 에 우위.
- 약점: R3(로우 블록 질식), R5 처벌(역습), R2(높은 라인 뒤), R1(BU 가 낮을 때). LOW_BLOCK 에 강열세, GEGENPRESS·HIGH_LINE 에 열세.
- 권장 역할: GK 스위퍼, CB 볼플레잉×2, FB 인버티드, DM 레지스타 또는 앵커, CM 딥 플레이메이커+메짤라, W 인사이드 포워드+인버티드 윙어, ST 폴스9.

#### (4) LOW_BLOCK 로우 블록 (카테나치오)
- 원리: 박스 앞 두 줄(5-3 또는 5-4)로 중앙·하프스페이스·뒷공간을 모두 지운다. 상대에게 공을 주고 역습·세트피스로 득점. 약점은 측면 크로스, 중거리, 세트피스 실점, 그리고 자기 진영에 오래 있어 코너·프리킥을 많이 준다.
- 요구: BOX ≥ 65, AER_D ≥ 60. 미달 시 R3 × BOX/65.
- 강점: R3(짧게 푸는 상대의 DP4 −), R11 무력화(5백), R2 무력화(뒷공간 없음, 상대 롱볼은 오히려 −), 자기 역습 R2(상대 라인이 높을 때). POSITIONAL 에 강우위, HIGH_LINE·GEGENPRESS 에 우위.
- 약점: R3 비용(DP2 중원 헌납), R4(측면 과부하·크로스), R13(타깃맨), 중거리(R3 해답), 크로스 증가 → 코너 실점 증가. WING_PLAY 에 강열세, DIRECT·WINGBACK_3 에 열세.
- 권장 역할: GK 전통, CB 스토퍼×2+커버, WB 수비형(FB_DEFENSIVE), DM 앵커, CM 박스투박스, ST 타깃맨+어드밴스드 포워드.

#### (5) MID_BLOCK_COUNTER 미드 블록 역습
- 원리: 중앙선 부근 4-4-2 두 줄로 기다리다 탈취 즉시 빠른 공격수에게 수직 패스. 상대가 공격적으로 올라올수록 뒷공간이 커진다. 공을 주는 상대(내려앉은 블록)에게는 공략할 공간이 없다.
- 요구: PACE_A ≥ 65(러너 1명 이상 속도 ≥ 15), MID ≥ 60. 미달 시 R2·R5 크기가 선수 속도 차 배수로 자연 감소.
- 강점: R5 처벌(상대 성향 ≥ +1), R2(상대 라인 ≥ +1), 2톱 커버 섀도(R7 방어). GEGENPRESS·WING_PLAY·HIGH_LINE 에 우위(속도 의존).
- 약점: R2 역효과(상대 라인 ≤ −1), 중원 2명(R7·R11 방어는 2톱 커버로 보완), 3백(3 대 2 수비)에게 러너가 묶임. WINGBACK_3 에 열세, BALANCED 에 약열세.
- 권장 역할: ST 어드밴스드 포워드+프레싱 포워드(또는 포처), W 와이드 미드필더, CM 박스투박스+볼 위닝, FB 수비형, CB 커버+스토퍼.

#### (6) DIRECT 다이렉트 롱볼·타깃맨
- 원리: 빌드업을 건너뛰고 타깃맨에게 길게. 세컨드볼을 중원이 줍고, 크로스·세트피스로 박스 안 공중전을 강요한다. 압박하는 팀에 가장 강하고, 키 큰 CB 를 가진 팀에 약하다.
- 요구: 타깃맨 역할 1명(공중전 AER ≥ 65 = 피지컬 ≥ 14), 세컨드볼 역할(볼 위닝 DM 또는 박스투박스) 1명 이상. 타깃맨이 없으면 R13 미발동.
- 강점: R13(DP1 롱볼 전진, DP2 세컨드볼), R2(상대 라인 높음), R1 무력화(패스 ≥ +1), 코너·프리킥 증가. GEGENPRESS 에 강우위, LOW_BLOCK·HIGH_LINE 에 우위.
- 약점: R13 음수(AER_D 가 높은 상대), 점유율 35~42%, 3백(공중 수적 우위). WINGBACK_3 에 열세, POSITIONAL·BALANCED 에 약열세.
- 권장 역할: ST 타깃맨+포처, W 와이드 미드필더 또는 윙어, CM 볼 위닝+박스투박스, CB 스토퍼×2, GK 전통.

#### (7) WING_PLAY 윙 플레이·크로스
- 원리: 폭을 최대로 벌려 측면 2 대 1(윙어+오버래핑 풀백)을 만들고 크로스·컷백. 좁게 서는 수비(다이아몬드, 3-5-2 의 중앙 밀집, 로우 블록)를 벌린다. 풀백이 올라가 역습 뒷공간이 생긴다.
- 요구: 측면 공격(SIDE_A) 평균 ≥ 60, 박스 안 공중 자원 AER_A ≥ 55. 미달 시 R4 × SIDE/60 (기존 widthFit).
- 강점: R4(측면 과부하), R12(3백 윙백 뒤 1:1), R3 해답(크로스). LOW_BLOCK 에 강우위, WINGBACK_3 에 우위.
- 약점: R5 처벌(성향 +1), 중앙 인원 부족(R7), R1(풀백 경유 짧은 빌드업이 사이드라인 압박 함정에 걸림). POSITIONAL·GEGENPRESS 에 열세, MID_BLOCK_COUNTER 에 약열세.
- 권장 역할: W 윙어×2, FB 공격형(오버래핑)×2, ST 타깃맨+포처, CM 박스투박스+딥 플레이메이커.

#### (8) HIGH_LINE 하이 라인 오프사이드 트랩
- 원리: 수비 라인을 하프라인 근처까지 올려 경기장을 25~30m 로 압축한다. 상대 중원은 공간이 없고, 너무 일찍 뛰는 침투는 오프사이드. 대가로 라인 뒤 수십 m 가 비어, 타이밍 좋은 러너(2선 침투)와 빠른 공격수에게 무너진다. **선수 의존도가 가장 큰 스타일**(수비수 속도 필수).
- 요구: CB 최저 속도 ≥ 13, PACE_D ≥ 65, 스위퍼 키퍼 권장. 미달 시 LINE_FIT(−0.6) 발동, 트랩 성공 절반.
- 강점: 압축(DP2 상대 전진 −, R7 방어에 가산), R6(상대 러너가 2선 침투 없이 최전방에만 있을 때), R1 약(press +1). BALANCED·POSITIONAL·WINGBACK_3 에 약우위.
- 약점: R2(빠른 러너 vs 느린 CB), R6 우회(메짤라·섀도 스트라이커·폴스9), LINE_FIT. MID_BLOCK_COUNTER·LOW_BLOCK·DIRECT 에 열세.

### 1.3 스타일 적합도 (UI 표시용, 엔진은 규칙 안의 배수만 사용)

`styleFit = min(1, Π 요구 항목별 (실제/요구))`, 표시: ≥ 95% 초록, 80~95% 노랑, < 80% 빨강 + 부족 항목 이름. 요구 항목은 `PresetDef.requirements` 데이터로 둔다(6.2). 엔진은 이 값을 직접 쓰지 않는다. 같은 조건이 규칙 안에서 배수(pressFit, widthFit, 선수 속도 차 등)로 이미 작동하므로 **UI 표시와 엔진 효과가 같은 요구치**를 쓰도록 상수를 공유한다(`FIT_REQUIREMENTS` 확장).

## 2. 실제 축구 논리 기반 상성 규칙

### 2.1 공통 정의 (엔진 내부, 계약 아님)

- 모든 크기는 **actor(성공을 원하는 팀) 관점 부호**. 원기여 `r_i` 를 만들고 famCoef·clamp 는 `decide()` 가 적용(기존과 같음).
- 능력치 `a.x` 는 1~20 원시 값에 포지션 적합도·컨디션을 곱한 유효값(`eff/5`). 유닛은 0~100.
- `tanhS(x, s) = tanh(x / s)`.
- **러너(runner)**: `ROLE_SHAPE.run = 1` 인 역할(포처, 어드밴스드 포워드, 인사이드 포워드, 섀도 스트라이커, 전통 윙어). `P_run` = 러너 중 최고 속도. 러너가 없으면 전방 3명 중 최고 속도 × 0.9.
- **2선 침투(deep runner)**: `ROLE_SHAPE.deep = 1` 인 역할(메짤라, 섀도 스트라이커, 박스투박스, 폴스9 가 내려가며 생긴 공간으로 들어오는 선수).
- `P_cb` = CB 슬롯 중 **최저 속도**. 커버 CB 가 있으면 `P_cb = 0.3 × 최저 + 0.7 × 커버 CB 속도`.
- **속도 배수** `paceMult = clamp(1 + (P_run − P_cb) / 4, 0.3, 1.6)`. 원시 4점(유닛 20점) 차에 ±100%. 기존 R2 의 `(PACE_A − PACE_D)/20` 과 같은 스케일이지만 평균이 아니라 **한 매치업**으로 정한다.
- **ROLE_SHAPE**(3.3 표): `cA` 중앙 공격 점유, `cD` 중앙 수비 커버, `wA` 측면 공격 인원, `wD` 측면 수비 인원, `hs` 하프스페이스 점유, `hsC` 하프스페이스 커버, `run`, `deep`.
- 팀 형태 합계는 경기 시작·교체·퇴장 때 `units.ts` 에서 유닛과 같이 계산한다(`TeamView.shape`, 엔진 내부).

### 2.4 "R7 중원 수적 우위로 4-4-2 가 항상 불리" 해결

**원인 (0.3.0)**: `centralMidfielders` 가 포메이션 상수(4-4-2 = 2, 나머지 3~4)라 4-4-2 는 거의 모든 상대에게 DP2 −0.16, DP8 −0.2 를 **지시·역할과 무관하게** 항상 받는다. 단독 P95 0.450 으로 가장 크고, "균형 4-4-2 가 가장 약한" 주 원인이었다(시뮬레이션_검증 7장).

**설계**
1. **유효 인원**: `C_att = Σ cA(공격 팀 역할)`, `C_def = Σ cD(수비 팀 역할)`. 폴스9·인버티드 FB·레지스타는 공격 때 중앙 인원을 늘리고, 트레콰르티스타·폴스9 는 수비 때 거의 기여하지 않는다(3.3 표).
2. **커버 섀도**: 수비 팀에 ST 가 2명이고 공격 팀의 DM(앵커·레지스타·볼 위닝) 이 1명이면 수비 cD +0.5. 2톱 중 하나가 단일 피벗을 지운다(실제 4-4-2 수비의 기본 원리). 수비 press ≥ 1 이면 +0.7.
3. **좁히기**: 수비 width ≤ −1 이면 와이드 미드필더 cD 0.2 → 0.5 (측면을 내주고 중앙을 닫는다 → R4 로 대가를 치른다).
4. **롱볼 무관**: 공격 directness ≥ 1 이면 R7 미발동(중원을 건너뛴다). R13 의 세컨드볼이 대신 작동.
5. **포화**: `tanh(C/1.5)` 로 3 대 5 같은 극단도 +0.3 에서 멈춘다. DP8 리셋은 절반 크기.

**계산 예 (중립 지시, 기본 역할)**

| 대진 | 4-4-2 공격 시 C | 4-3-3 공격 시 C | 4-4-2 측면 O(한쪽) | 결과 |
|---|---|---|---|---|
| 0.3.0 | 2 − 3 = −1 → DP2 −0.16 (항상) | +1 → +0.16 | R4 미발동(4-3-3 은 좁지 않음) | 4-4-2 일방 불리 |
| 0.4.0 | cA: 박스투박스 1.0 × 2 + 와이드 MF 0.1 × 2 = 2.2 vs cD: 앵커 1.0 + 박스투박스 0.8 + 공격형 플레이메이커 0.3 + 윙어 0.1 + 인사이드 포워드 0.1 = 2.3 → C = −0.1 → DP2 −0.02 | cA: 앵커 0.8 + 박스투박스 1.0 + 플레이메이커 1.0 + 윙어 0.1 + 인사이드 포워드 0.2 = 3.1 vs cD: 박스투박스 0.8 × 2 + 와이드 MF 0.2 × 2 + 커버 섀도 0.5 + 타깃맨 0.1 = 2.6 → C = +0.5 → DP2 +0.10 | wA: 와이드 MF 0.8 + 수비형 FB 0.3 = 1.1 vs wD(4-3-3): 수비형 FB 1.0 + 윙어 0.4 = 1.4 → 미발동. 공격형 FB 로 바꾸면 1.7 − 1.4 = 0.3 → R4 발동 | 4-3-3 쪽 +0.10 vs 0.3.0 의 ±0.16 양방향(순 0.32 차) → 순 차이 약 0.12, 역할·지시(공격형 FB, 프레싱 포워드 커버 섀도 +0.7, 폭 +1)로 상쇄·역전 가능 |

전제: 4-4-2 의 W 슬롯 기본 역할을 전통 윙어 → **와이드 미드필더**로 바꾼다(실제 4-4-2 의 측면 MF). 계산은 `formations.ts` 현재 기본 역할(4-3-3: 앵커·박스투박스·플레이메이커·윙어·인사이드 포워드, 4-4-2: 타깃맨+포처) 기준.

**검증 기준**: FORMATION_PARITY(5장) — 중립 지시·기본 역할 라운드로빈에서 모든 포메이션 경기당 승점 1.25~1.50, 4-4-2 vs 4-3-3 (승 − 패) 절댓값 ≤ 6%p. R7 단독 P95 ≤ 0.30 xG(0.450 에서 하향).

### 2.5 스타일 × 스타일 상성 행렬 (기대 방향)

## 8. 열린 질문 / 가정

1. **가정**: 실제 리그 통계는 근사치다. P0-a 착수 전 최신 2시즌 수치 확인이 필요하다(특히 경고 수, 추가시간 규정 변화 이후 후반 골 비중).
2. **가정**: 선수 능력치 1~20 척도와 유닛 0~100 의 관계(×5)는 유지한다. paceMult 의 스케일 4(원시)는 기존 20(유닛)과 같다.
3. **결정 필요**: 추가시간으로 늘어나는 득점(+≈0.2)을 목표 상향(2.6~3.0)으로 흡수할지(권장), `BASE_SEQUENCES` 를 줄일지.
4. **결정 필요**: 스타일 적용 시 포메이션까지 바꾸는 버튼을 제공할지(숙련도 × 0.5 비용이 크다). 권장: 제공하되 경고.
5. **위험**: 규칙 3개 추가로 DP 당 cap 에 닿는 빈도가 늘면 상성이 "상한 포화"로 평평해질 수 있다. STYLE_MATRIX ⑤(부호 일치율)로 감지하고, 포화가 심하면 개별 규칙 크기를 cap 이하(0.3~0.5)로 낮춰 규칙 간 합산이 의미를 갖게 한다.
6. **위험**: 역할 28종은 모바일에서 선택 피로를 만든다. 스타일 선택 시 권장 역할을 자동 채우고, 역할 시트는 "권장 → 기타" 순으로 정렬한다.
