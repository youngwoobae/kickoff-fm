## 발견한 문제 (코드 수정 안 함)

1. **[중] 합류 당일 코치의 '빠른 제안'이 아무 반응 없음.** 민수 추가 직후 '변경 1건 제안하기' → 이유 입력 → '제안 보내기'를 눌러도 시트가 닫히지 않고 토스트·오류도 없다. 같은 조작을 기존 '전술 코치'로 하면 제안이 생긴다. `src/ui/plan/PlanActions.tsx:48` `if (!planState?.matchId) return;` 이 조용히 끝난다(합류 당일 플랜 열람 제한과 겹침). 버튼을 막거나 이유를 보여 줘야 한다
2. **[중] 골키퍼가 1명뿐이어도 경고 없음, 컨디션 16 GK 가 계속 선발.** 결과 시트 "[플랜 보정] 최지수 컨디션 16 < 70 → 신한결 선발 / [플랜 보정] GK 자리에 최지수 배치"가 매일 반복. GK 만료를 막거나 알리는 장치가 없다(재계약 협상 편지는 인원만 알림)
3. **[중] 시즌 판정 알림에 영어 코드 노출.** "최종 순위 2위 — PROMOTED", "— STAYED", "— RELEGATED". `src/domain/day/advanceDay.ts:594`
4. **[하] 이적료 장부 "이적료 지급 0".** 이적 한정 예산으로 낸 이적료가 결과 시트에 0 으로 두 줄 찍힌다(S2 Day 1). 잔액은 맞다(한정 예산 14.62M − 9.02M = 소멸 5.60M)
5. **[하] 금액 표기 불일치.** 방출 버튼 "위약금 44K", 편지 "위약금 0.04M"
6. **[하] 설정 '여러 날 진행 전 확인'이 출시 빌드에서 쓸 곳이 없음.** 여러 날 진행(`advanceToSeasonEnd`)은 개발자 패널에만 있다
7. **[하] 375 폭 헤더 잘림.** "성수 유나…", "S4 · Day 16/…" — 시즌·날짜·잔액이 보이지 않는다(`dod-20-replay-2d.png`)
8. **[문서] 성능 여유 주장과 측정 불일치.** `README_진행보고.md` 85행 "4× 스로틀 실측(여유 7%)" 언급과 달리 이번 측정은 기준의 2.6배(15번)
