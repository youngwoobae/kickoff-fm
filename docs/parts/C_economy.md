## 7. 구단 예산과 보상 경제

### 7.1 "실제 사용 가능한 예산"의 정의: 게임 내 재화로 확정

원 요청의 "실제 사용 가능한 예산"은 **게임 안에서만 쓰는 재화(KC)**로 설계합니다. 현금이나 현금성 가치와는 연결하지 않습니다.

| 구분 | 무엇인가 | 현금으로 살 수 있나 | 현금으로 바꿀 수 있나 | 경쟁력에 영향 |
|---|---|---|---|---|
| **구단 운영 예산 (KC)** | 이적료, 주급, 시설, 스카우트에 쓰는 돈. 원 요청의 "실제 사용 가능한 예산"에 해당 | **불가** | **불가** | 있음. 그래서 플레이로만 얻음 |
| **샐러리캡** | 재화가 아니라 **지출 한도**. KC가 많아도 주급 총액은 이 선을 넘을 수 없음 | 해당 없음 | 해당 없음 | 공정성 장치 |
| **프리미엄 재화 (스타 ★)** | 유료 구매 재화. 코스메틱과 편의 기능 전용 | 가능 | 불가 | **없음**. KC로 바꿀 수 없음 |
| **레거시 포인트 (LP)** | 이월 상한을 넘긴 KC가 바뀌는 명예 점수. 트로피룸과 구단 역사 꾸미기 전용 | 불가 | 불가 | 없음 |
| **이벤트 토큰** | 기간 한정 이벤트 재화. 이벤트 종료 후 7일이 지나면 소멸 | 불가 | 불가 | 없음. 보상은 코스메틱 위주 |
| **현금성 보상** | **별도 선택지. 이 문서에서는 설계하지 않음** (법률·운영 검토는 법무 담당) | - | - | 7.12에 경제 영향만 적음 |

> 핵심 원칙: **돈으로 살 수 있는 재화는 경기력에 닿지 않고, 경기력에 닿는 재화는 돈으로 살 수 없다.**

### 7.2 재화 명세

#### 구단 운영 예산 (KC)
- **목적**: "지금 영입할까, 아껴 둘까", "스타 1명에 몰아줄까, 주전 여러 명을 고르게 쓸까" 같은 선택을 만든다.
- **유형**: 소프트 재화. 구단 단위로 보유하며 계정 간 이동은 불가.
- **소스**: 시즌 기본 배정금, 경기 수당(승/무/패), 순위 상금, 우승 수당, 승격 보너스, 강등 낙하산, 선수 판매 대금(세금 공제 후).
- **싱크**: 선수 주급, 이적료(시스템 시장·경매), 이적세, 계약 갱신 보너스, 방출 위약금, 스카우트 파견비, 시설 유지비·업그레이드, 시즌 종료 시 이월 상한 초과분(LP로 전환).
- **수입/지출 목표 비율**: 중위권 팀 기준 시즌 수입 : 시즌 지출 = **1.05~1.10 : 1**. 흑자는 이월 상한 안에서만 남는다.
- **보유 상한**: 시즌 중에는 상한 없음. 시즌 종료 시 **다음 시즌 기본 배정금의 20%**까지만 이월.
- **전환 경로**: KC에서 LP로 가는 한 방향만 존재(1M KC = 1 LP). 스타(★)와 KC 사이의 전환은 양방향 모두 없음.
- **악용 위험**: 부계정 몰아주기, 시장 조작, 탱킹. 대응은 13장 참고.

#### 프리미엄 재화 (스타 ★)
- **목적**: 구단 정체성 표현과 편의 기능.
- **소스**: 인앱 구매, 소량 무료 지급(시즌 패스 무료 트랙과 업적으로 시즌당 약 150★).
- **싱크**: 코스메틱 상점, 시즌 패스 프리미엄 트랙, 구단명·엠블럼 변경.
- **금지**: KC, 선수, 능력치, 정보, 시간 단축 구매.

### 7.3 경제 흐름도

```
[리그 경기] --수당--> [KC 구단 예산] --지출--> [주급 / 이적료 / 시설 / 스카우트]
[시즌 결과] --상금·우승·승격·낙하산--> [KC]
[선수 판매] --대금(이적세 10% 차감)--> [KC]
[시즌 종료] --잔액 중 이월 상한 이내--> [다음 시즌 KC]
            --이월 상한 초과분--> [레거시 포인트 LP] --> 트로피룸 / 구단 역사 (경기력 영향 없음)
[인앱 결제] --> [스타 ★] --> [코스메틱 / 시즌 패스 / 편의]    (KC로 가는 경로 없음)

모든 루프의 종착점: 주급·이적세·시스템 이적료·시설비(싱크) 또는 이월 상한(캡)
```

닫힌 루프 점검:

| 소스 | 최종 배출 경로 |
|---|---|
| 기본 배정금, 경기 수당, 상금 | 주급(가장 큰 싱크), 시스템 이적료, 시설비 → 소멸 |
| 선수 판매 대금 | 판매 시 이적세 10% 소멸, 나머지는 다시 주급·이적료로 순환 |
| 쓰지 않고 남은 돈 | 이월 상한 초과분이 LP로 전환(경제에서 빠짐) |
| 낙하산 자금 | 주급과 방출 위약금에만 쓸 수 있음 → 소멸 |

### 7.4 티어별 예산·보상 수치표 (제안 기본값)

단위는 M KC(백만 KC). 티어가 하나 오를 때마다 약 1.55배 커지도록 설계했습니다.

#### 7.4.1 시즌 예산과 경기 수당

| 티어 | 시즌 기본 배정금 | 샐러리캡 (시즌 주급 총액) | 승리 수당 | 무승부 수당 | 패배 참가 수당 | 26경기 전승 시 수당 |
|---|---|---|---|---|---|---|
| T1 프리미어 | 200.0 | 150.0 | 3.00 | 1.20 | 0.40 | 78.0 |
| T2 챔피언십 | 130.0 | 98.0 | 2.00 | 0.80 | 0.30 | 52.0 |
| T3 리그 1 | 85.0 | 64.0 | 1.30 | 0.50 | 0.20 | 33.8 |
| T4 리그 2 | 55.0 | 41.0 | 0.85 | 0.35 | 0.12 | 22.1 |
| T5 입문 리그 | 35.0 | 26.0 | 0.55 | 0.20 | 0.08 | 14.3 |

설계 근거:
- **샐러리캡 = 기본 배정금의 75%**: 성적이 나빠 수당을 거의 못 받은 팀도 캡을 끝까지 채울 수 있다. 캡은 부자 팀을 막는 장치이면서, 가난한 팀도 도달할 수 있는 선이어야 한다.
- **무승부 수당 = 승리의 약 40%**: 원정에서 "지지 않는 플랜"도 전술적으로 의미 있는 선택이 된다.
- **패배 참가 수당**: 플랜을 제출했거나 AI 대행으로 경기를 치르면 지급한다. 매일 접속하지 못하는 유저의 최저 수입을 보장한다(섹션 3, 9와 연계).
- **성과 수입 비중 상한은 약 40%**: 우승 팀도 전체 수입의 약 60%는 기본 배정금에서 나온다. 이기면 확실히 보상받지만, 한 시즌 성적이 다음 시즌 격차를 결정적으로 벌리지는 못한다.

#### 7.4.2 순위 상금·우승 수당·승격 보너스·강등 낙하산

순위 상금은 **해당 티어 기본 배정금 대비 비율**로 정의해 티어별로 자동 계산합니다.

| 최종 순위 | 순위 상금 (배정금 대비) | T1 | T2 | T3 | T4 | T5 |
|---|---|---|---|---|---|---|
| 1위 | 20% | 40.0 | 26.0 | 17.0 | 11.0 | 7.0 |
| 2~3위 | 15% | 30.0 | 19.5 | 12.75 | 8.25 | 5.25 |
| 4~6위 | 10% | 20.0 | 13.0 | 8.5 | 5.5 | 3.5 |
| 7~10위 | 6% | 12.0 | 7.8 | 5.1 | 3.3 | 2.1 |
| 11~14위 | 3% | 6.0 | 3.9 | 2.55 | 1.65 | 1.05 |
| **우승 수당** (1위 추가 지급) | 10% | 20.0 | 13.0 | 8.5 | 5.5 | 3.5 |

| 이동 | 승격 보너스 (다음 시즌 시작 시 1회) | 강등 낙하산 (1시즌 한정) | 샐러리캡 유예 |
|---|---|---|---|
| T2 → T1 | 30.0 (T1 배정금의 15%) | - | - |
| T3 → T2 | 19.5 | - | - |
| T4 → T3 | 12.75 | - | - |
| T5 → T4 | 8.25 | - | - |
| T1 → T2 강등 | - | 35.0 | 새 캡의 120%까지 1시즌 허용 |
| T2 → T3 강등 | - | 22.5 | 동일 |
| T3 → T4 강등 | - | 15.0 | 동일 |
| T4 → T5 강등 | - | 10.0 | 동일 |

- **승격 보너스 = 새 티어 배정금의 15%**: 새 티어 캡에 맞춰 선수를 보강할 초기 자금이다. 승격 직후 바로 다시 강등되는 요요 현상을 줄인다.
- **강등 낙하산 = (이전 티어 배정금 - 새 티어 배정금) x 50%**
  - 쓸 수 있는 곳을 **주급과 방출 위약금으로 제한**한다. 이적료에는 쓸 수 없다. 낙하산 자금으로 하위 리그를 휩쓰는 것을 막고, 비싼 선수단을 정리하는 비용에만 쓰게 하기 위함이다.
  - 캡 유예: 강등 시즌에는 새 캡의 120%까지 허용한다. 다음 시즌 시작 전까지 캡 이하로 줄이지 못하면 초과분만큼 **선발 가능 인원이 제한**된다(캡 초과 선수부터 출전 불가).
  - 추가로 **무위약 방출권 2장**을 준다(해당 선수는 경매 시장으로 이동).
- **T5 신규 구단**: 첫 시즌에 신규 지원금 5.0M을 추가 지급한다. 온보딩(섹션 9)과 연계하며, 부계정 파밍을 막기 위해 계정당 1회만 준다.

### 7.5 한 티어의 시즌 수입/지출 계산 예시

**상황**: T3 리그 1, 중위권 구단. 12승 6무 8패로 5위. 전 시즌 이월금 8.0M.

| 수입 항목 | 계산 | 금액 (M) |
|---|---|---|
| 시즌 기본 배정금 | T3 고정 | 85.0 |
| 전 시즌 이월금 | 상한(85 x 20% = 17.0) 이내 | 8.0 |
| 승리 수당 | 12 x 1.30 | 15.6 |
| 무승부 수당 | 6 x 0.50 | 3.0 |
| 패배 참가 수당 | 8 x 0.20 | 1.6 |
| 순위 상금 | 5위, 배정금의 10% | 8.5 |
| 선수 판매 대금 | 매각 15.0M에서 이적세 10% 차감 | 13.5 |
| **수입 합계** | | **135.2** |

| 지출 항목 | 계산 | 금액 (M) |
|---|---|---|
| 선수 주급 | 22명, 캡 64.0M의 94% 사용 | 60.0 |
| 이적료 (경매 1명 + 시스템 시장 1명) | 18.0 + 12.0 | 30.0 |
| 이적세 (구매 측 5%) | 30.0 x 5% | 1.5 |
| 계약 갱신 보너스 | 주전 3명 재계약 | 5.0 |
| 방출 위약금 | 1명, 잔여 주급의 50% | 2.0 |
| 스카우트 파견비 | 지역 파견 4회 x 1.0 | 4.0 |
| 시설 유지비 | 훈련장 Lv3·의료 Lv2 | 6.0 |
| 유스 아카데미 업그레이드 | Lv2 → Lv3 | 8.0 |
| **지출 합계** | | **116.5** |

| 시즌 종료 정산 | 금액 (M) |
|---|---|
| 잔액 | 135.2 - 116.5 = **18.7** |
| 다음 시즌 이월 (상한 17.0) | **17.0** |
| LP 전환 (초과분) | 1.7M → **1.7 LP** |

읽는 법:
- 흑자가 이월 상한을 조금 넘었다. "남기면 손해니 시즌 막바지에 쓸 곳을 찾자"는 결정이 생긴다. 의도한 동작이다.
- 같은 T3에서 **최하위(4승 5무 17패)**여도 배정금과 수당, 상금을 합쳐 약 98.6M을 받는다. 샐러리캡 64.0M을 채우고도 약 35M이 남으므로 재건이 가능하다.
- **T3 우승 팀(20승 4무 2패)** 수입은 약 138.9M(이월 제외)이다. 최하위보다 약 41% 많지만, 주급은 같은 캡(64.0M)에 묶인다. 차이는 이적료, 시설, 이월(상한 17.0M)로만 나타난다.

### 7.6 90일(3시즌) 아키타입 시뮬레이션 요약

시즌마다 기본 배정금이 새로 지급되고 이월 상한이 있으므로, 보유 잔액은 누적되지 않고 상한 근처에서 멈춥니다. 과금 유저도 KC 이점이 0이므로 같은 곡선을 따릅니다.

| 아키타입 | 접속 패턴 | 위치 (1→3시즌) | 시즌 수입 (M) | 시즌 지출 (M) | 30일차 이월 | 90일차 이월 | 판정 |
|---|---|---|---|---|---|---|---|
| 캐주얼 | 주 3~4회, 나머지는 AI 대행 | T4 중하위 유지 | 약 70 | 약 58 | 11.0 (상한) | 11.0 (상한) | 정상. 초과분은 LP로 |
| 코어 | 매일 플랜 제출 | T4 → T3 → T3 | 74 → 110 → 114 | 65 → 100 → 105 | 8.3 | 9.0 | 정상 |

- 본인 인증 계정만 대상으로 하는 것을 경제 쪽 최소 조건으로 제안합니다.

## 담당 범위 미결정 질문

1. **리그 규모와 승강 수**: 14팀, 5티어, 상위 2팀 승격/하위 4팀 강등이라는 가정이 섹션 6과 맞나요? 바뀌면 수당·상금 공식은 그대로 두고 수치만 다시 계산합니다.
2. **유저 간 직접 트레이드**: MVP에서 공개 경매만 허용하는 안에 동의하나요? 직접 트레이드는 재미가 크지만 부계정 악용 비용도 가장 큽니다.
3. **이월 상한 20%와 LP 전환**: 남은 돈이 사라지는 것에 대한 유저 반감을 어느 정도까지 감수할까요? 대안으로 초과분 50%를 유스 아카데미에 자동 투자하는 방법이 있습니다.
4. **시설 시스템의 전력 영향 폭**: 시설이 훈련 효율이나 부상률에 주는 효과의 상한은 몇 %로 둘까요? (제안: 최대 +10%) 섹션 4·8 담당과 합의가 필요합니다.
5. **AI 대행 경기의 수당**: 미접속일 AI 대행 경기의 승리 수당도 100% 지급할까요, 아니면 일부만(예: 70%) 지급할까요? 접속 동기 부여와 미접속 유저 보호 사이의 균형 문제입니다.
6. **구단주 멤버십과 플랜 프리셋**: 플랜 프리셋 저장 슬롯 확장을 "편의"로 보고 판매할지, "경쟁 요소"로 보고 금지할지 결정이 필요합니다. 현재 안은 금지입니다.
7. **시즌 패스 무료 트랙의 KC 보상**: 무료·유료 트랙 모두 KC를 0으로 둘지, 두 트랙에 같은 소량의 KC를 넣을지 결정이 필요합니다.
8. **현금성 보상 도입 여부**: 도입한다면 대상 티어와 순위, KC 경제와의 분리 방식을 법무 파트 결론과 함께 확정해야 합니다.
9. **시즌 중 신규 가입·복귀 구단**: 시즌 중간에 들어온 구단의 기본 배정금을 남은 일수만큼 비례 지급할지, 전액 지급할지 정해야 합니다.
10. **가격대와 지역화**: 스타 팩과 시즌 패스의 원화 가격, 해외 출시 시 지역별 가격 책정 방식은 사업 담당의 확인이 필요합니다.
