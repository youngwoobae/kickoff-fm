# 12. MVP 기능과 후속 업데이트

## 12.1 MVP 범위 원칙

MVP가 검증해야 할 질문은 하나다. **"하루 한 번 플랜을 제출하고 저녁 경기 결과를 확인하는 루프가 한 달 시즌 동안 유지되는가, 그리고 코치 협동이 그 루프를 더 강하게 만드는가."**

| 원칙 | 내용 | 적용 예시 |
|------|------|-----------|
| 핵심 루프 우선 | 플랜 제출 → 경기 → 결과·분석 → 다음 플랜 수정. 이 고리를 끊는 기능만 넣는다 | 경기 리포트는 MVP에 넣고 3D 하이라이트는 뺀다 |
| 차별점은 최소 형태라도 포함 | 코치 협동은 이 게임의 차별점이므로 MVP에서 빼면 가설 검증이 불가능하다 | 코치 5인 초대 + 고정 역할 권한 + 제안/승인은 포함, 역할 커스터마이징은 제외 |
| 공정성 장치는 선행 | 경쟁 게임에서 공정성이 한 번 무너지면 되돌리기 어렵다 | 비활성 팀 AI 대행, 담합 탐지 로그는 MVP 포함 |
| 수익화는 가볍게 | MVP의 목적은 매출이 아니라 리텐션 검증이다 | 코스메틱 상점 1종만, 시즌 패스는 1차 |
| 운영 가능성 | 라이브 경쟁 게임은 운영툴이 없으면 첫 주에 멈춘다 | 제재·리그 재배정·보상 재지급 툴은 MVP 포함 |

**출시 단계 가정 (임시)**

| 단계 | 기간 | 규모 | 목적 |
|------|------|------|------|
| 테크 테스트 | 2주 | 내부 + 초대 200명 | 경기 엔진 안정성, 정시 경기 일괄 처리 부하 |
| CBT | 1시즌(4주) | 2,000~5,000명 | 핵심 루프 리텐션, 코치 협동 사용률 |
| 소프트 런칭 | 2시즌 | 1개 권역 | KPI 게이트 통과 여부 판단 |
| 정식 출시 | - | 목표 권역 | 1차 업데이트 준비 상태에서 출시 |

## 12.2 영역별 MVP / 1차 / 2차 이후

"1차"는 정식 출시 후 약 1~3개월(2~3시즌), "2차 이후"는 그 이후를 뜻한다. 일정은 가정이며 KPI 결과에 따라 순서가 바뀐다.

| 영역 | MVP | 1차 업데이트 | 2차 이후 |
|------|-----|-------------|---------|
| **경기 엔진** | 2D 탑뷰 이벤트 기반 시뮬레이션, 텍스트 중계 + 주요 장면 2D 재생, 경기 통계(점유율·슈팅·xG·패스맵), 서버 측 결정론적 시드 처리 | 하프타임 조건부 지시 확장(스코어·시간·퇴장 조건), 경기 후 "전술 영향 분석" 리포트 | 3D/고품질 하이라이트, 날씨·잔디 등 환경 변수, 실시간 관전 중 제한적 개입 |
| **전술** | 포메이션 8~10종, 선수 역할 기본 세트, 팀 지시 5~6축(라인 높이, 압박 강도, 템포, 폭, 빌드업 방식, 수비 방식), 경기 플랜 1개 + 대체 플랜 1개, 세트피스 기본 설정 | 상대별 맞춤 플랜 저장 슬롯 확대, 세트피스 상세 설계, 전술 프리셋 공유(팀 내부) | 전술 공유 마켓(비거래형), 개인 선수 상세 지시, 훈련 연계 전술 숙련도 |
| **선수단** | 가상 선수 풀, 25인 스쿼드, 능력치·포지션 숙련·컨디션·부상·출장 피로, 기본 성장(나이 기반) | 유스 아카데미, 선수 계약 기간·재계약, 팀 케미스트리 | 선수 은퇴·코치 전환, 선수 성격/멘탈 이벤트, 레전드 선수 |
| **리그** | 월간 시즌(약 4주), 단일 권역 피라미드(예: 4~5 디비전), 승격·강등, 순위표, 시즌 종료 보상, 신규 유저 입문 리그 | 컵 대회(주말 토너먼트), 시즌 중간 이적 마감일, 명예의 전당 | 권역 간 챔피언스 대회, 친선전/스크림, 커뮤니티 커스텀 리그 |
| **경제** | 게임 내 재화 단일 예산(구단 자금), 승리·무승부 수당, 순위·우승 수당, 리그별 예산 차등, 주급 부담, 이적시장(구매·판매) | 스폰서 계약 선택지, 경기장 수입/시설 투자, 시장 가격 안정화 장치 고도화 | 구단 가치 평가, 장기 부채/투자 시스템. 현금성 보상은 법률 검토 통과 시에만 별도 트랙 |
| **협동** | 코치 최대 5인 초대, 고정 역할 5종(전술·스카우트·선수단·분석·재정), 역할별 권한, 제안→구단주 승인 흐름, 팀 내 채팅, 변경 이력 로그 | 역할 권한 커스터마이징, 코치 투표 기능, 경기 전 전술 회의 화면(공동 편집 잠금) | 코치 평판/경력 시스템, 코치 모집 게시판, 코치 전용 보상 트랙 |
| **온보딩** | 튜토리얼 경기 3회(AI 상대), 추천 전술 자동 설정, 입문 리그(봇 섞임) 배정, "오늘 할 일" 체크리스트 | 전술 코칭 팁(경기 결과 기반 "다음엔 이렇게"), 코치 초대 유도 퀘스트 | 멘토 매칭(상위 유저가 신규 팀 코치로 합류 시 보상) |
| **수익화** | 코스메틱 상점(유니폼·엠블럼·경기장 테마), 광고 없음 | 시즌 패스(코스메틱 + 편의 기능, 능력치 없음), 스쿼드 추가 플랜 슬롯 등 편의 상품 검토 | 구독형 "구단 프리미엄"(통계 확장·리플레이 보관), 크리에이터/리그 후원 |
| **운영툴** | 유저·팀 조회, 제재(경고·정지·영구), 경기 재처리/결과 무효, 보상 재지급, 리그 재배정, 담합·비활성 탐지 대시보드, 공지 발송 | 밸런스 모니터링 대시보드(포메이션·전술 승률), A/B 실험 플래그, CS 티켓 연동 | 자동 제재 파이프라인, 이상 거래 ML 탐지, 시즌 시뮬레이터(밸런스 사전 검증) |

## 12.3 MVP 제외 항목과 이유

| 제외 항목 | 제외 이유 | 다시 넣는 조건 |
|-----------|----------|---------------|
| 3D 경기 연출 | 제작 비용이 가장 크고 핵심 루프 검증과 무관. 전술 이해에는 2D 탑뷰가 더 명확함 | 경기 시청 완료율이 높고(예: 60%+) "보는 재미" 요구가 VOC 상위 3위 안에 들 때 |
| 경기 중 실시간 개입 | 매일 접속 못 하는 유저를 불리하게 만듦(작성 기준 위배), 정시 일괄 처리 서버 부하 증가 | 조건부 지시로 충분하지 않다는 데이터 + 비접속 유저 보정 장치 설계 완료 시 |
| 컵 대회 | 리그만으로 월간 루프가 성립하는지 먼저 확인해야 함. 경기 수 증가는 피로도 위험 | D30 리텐션 목표 달성 + 시즌 중반 이탈 구간 확인 시 |
| 유스 아카데미·계약 | 선수단 깊이를 늘리지만 신규 유저 복잡도 증가 | 3시즌 이상 유저 비율이 의미 있게 생기고 "할 게 없다" VOC 발생 시 |
| 역할 권한 커스터마이징 | 권한 조합 폭발로 QA·분쟁 처리 비용 급증. 고정 5역할로 충분한지 먼저 확인 | 구단주의 30% 이상이 권한 부족/과다 불만을 제기할 때 |
| 시즌 패스 | MVP는 리텐션 검증이 목적. 보상 구조가 경제와 얽혀 초기 밸런스 판단을 흐림 | 경제 밸런스가 2시즌 연속 안정된 후 |
| 권역 간 대회 | 시간대 공정성 문제가 해결되지 않은 상태에서 도입하면 불만만 증가 | 권역별 서버가 2개 이상 안정 운영될 때 |
| 전술 공유 마켓 | 메타 고착을 가속할 위험. 먼저 메타 다양성 지표를 관찰해야 함 | 포메이션 다양성 지표가 목표 이상 유지될 때 |
| 실존 선수/리그 라이선스 | 라이선스 비용·협상 기간이 MVP 일정을 초과 | 사업 결정(핵심 질문 Q4) 이후 |
| 현금성 보상 | 사행성·경품 규제, 세무, 연령 제한 등 법률 검토 필수 | 법률·운영 검토 통과 후 별도 트랙으로만 |
| 자동 제재 파이프라인 | 오탐 시 경쟁 게임 신뢰를 크게 훼손. MVP는 탐지→사람 검토 | 수동 제재 데이터로 탐지 규칙 정밀도 90%+ 확인 후 |

## 12.4 MVP 성공 지표(KPI)

수치는 장르 벤치마크 기반의 **초기 가정 목표**이며, CBT 데이터로 재보정한다.

| 구분 | 지표 | 정의 | 목표(가정) | 경고선 |
|------|------|------|-----------|--------|
| 리텐션 | D1 / D7 / D30 | 설치 후 해당 일 접속 | 45% / 25% / 12% | 35% / 15% / 6% |
| 리텐션 | 시즌 완주율 | 시즌 시작 팀 중 마지막 라운드까지 플랜 제출(수동 또는 저장 플랜)한 팀 비율 | 60% | 40% |
| 리텐션 | 다음 시즌 재참여율 | 시즌 완주 팀 중 다음 시즌 참가 | 75% | 55% |
| 핵심 루프 | 일일 수동 플랜 제출률 | 활성 팀 중 경기 전 플랜을 직접 수정·확정한 비율 | 50% | 30% |
| 핵심 루프 | 경기 결과 확인률 | 경기 후 24시간 내 결과/리포트 열람 | 70% | 50% |
| 핵심 루프 | 전술 변경 빈도 | 주당 전술 설정 변경 횟수 중앙값 | 2회 이상 | 0.5회 미만 |
| 협동 | 코치 보유 팀 비율 | 코치 1명 이상 있는 활성 팀 | 30% | 15% |
| 협동 | 코치 유지율 | 초대 수락 코치의 14일 후 활동 | 50% | 30% |
| 협동 | 협동 팀 리텐션 우위 | 코치 보유 팀 vs 솔로 팀 D30 차이 | +8%p 이상 | 0 이하 |
| 협동 | 권한 분쟁 신고율 | 코치 보유 팀 중 분쟁 신고 발생 | 5% 미만 | 10% 이상 |
| 공정성 | 전술 영향 체감 | 설문 "내 전술이 결과에 영향을 준다" 동의 | 65% | 45% |
| 공정성 | 운 불만 비율 | 설문/VOC 중 "운빨·조작" 관련 비중 | 15% 미만 | 30% 이상 |
| 공정성 | 비접속 불이익 | 주 3일 이하 접속 팀의 평균 승점 vs 매일 접속 팀 | 격차 25% 이내 | 40% 이상 |
| 메타 | 포메이션 다양성 | 상위 디비전에서 가장 많이 쓰인 포메이션 점유율 | 30% 미만 | 50% 이상 |
| 리그 | 비활성 팀 비율 | 7일 이상 미접속 팀 비율(디비전별) | 15% 미만 | 25% 이상 |
| 기술 | 정시 경기 처리 성공률 | 예정 시각 +5분 내 결과 산출 | 99.9% | 99% |
| 수익 | 결제 유저 비율(참고) | MVP 검증 대상 아님, 관찰만 | 관찰 | - |

## 12.5 검증 가설

| # | 가설 | 검증 방법 | 통과 기준 | 실패 시 대응 |
|---|------|----------|----------|------------|
| H1 | 하루 1경기 + 사전 플랜 제출은 "짧지만 매일 오는" 습관을 만든다 | CBT 코호트의 일일 플랜 제출률·세션 길이 | 수동 제출률 50%+, 평균 세션 5~15분 | 경기 빈도(하루 2경기/주말 휴식) A/B, 알림 타이밍 조정 |
| H2 | 전술 선택이 결과에 체감될 만큼 영향을 준다 | 동일 전력 팀 간 전술 상성별 승률 로그 + 설문 | 유리 상성 승률 55~62%, 체감 동의 65%+ | 62% 초과 시 운 요소 증가, 55% 미만 시 전술 가중치 증가 |
| H3 | 코치 협동은 리텐션을 높인다 | 코치 보유 팀 vs 솔로 팀 D30 비교(가입 시점·실력 통제) | +8%p 이상 | 초대 UX 개선, 코치 전용 보상 조기 도입, 역할 재설계 |
| H4 | 구단주 최종 승인 구조가 협동의 재미를 해치지 않는다 | 코치 제안 승인율, 코치 이탈 사유 설문 | 제안 승인율 40%+, "권한 부족" 이탈 사유 20% 미만 | 구단주 위임 옵션 확대(1차 커스터마이징 앞당김) |
| H5 | 비접속 보정(저장 플랜·AI 대행)으로 가끔 접속 유저도 경쟁할 수 있다 | 접속 빈도별 승점·강등률 | 주 3일 접속 팀 강등률이 매일 접속 팀의 1.5배 이내 | AI 대행 품질 향상, 플랜 자동 반복 옵션 강화 |
| H6 | 한 달 시즌 길이가 적절하다 | 시즌 주차별 이탈 곡선 | 3~4주차 이탈이 1~2주차의 1.3배 이내 | 3주 시즌 또는 시즌 중간 이벤트(컵) 도입 |
| H7 | 승격·강등이 동기부여가 되고 좌절을 과도하게 만들지 않는다 | 강등 팀의 다음 시즌 재참여율 | 강등 팀 재참여 60%+ | 강등 완충(강등 보호권, 하위 리그 보상 상향) |

# 13. 악용·밸런스 문제와 대응책 (경제 외)

> 부계정 선수 몰아주기, 탱킹, 이적시장 조작 등 **경제 악용은 경제 담당 섹션**에서 다룬다. 아래는 경쟁·협동·운영 측면의 악용과 밸런스 문제다.

## 13.1 대응 원칙

| 원칙 | 설명 |
|------|------|
| 탐지 → 사람 검토 → 제재 | MVP에서는 자동 제재 없이 탐지 규칙이 후보를 올리고 운영자가 판단한다. 오탐은 경쟁 게임에서 가장 비싼 실수다 |
| 설계로 먼저 막기 | 탐지보다 "애초에 이득이 없게" 만드는 설계가 우선이다 (예: 담합으로 얻을 수 있는 승점 자체를 줄임) |
| 모든 권한 행동은 로그 | 코치·구단주의 모든 변경은 누가/언제/무엇을/이전 값과 함께 기록한다 |
| 투명한 제재 기준 | 제재 사유와 단계를 공개하여 "운영 임의 판단" 불신을 줄인다 |

## 13.2 시나리오 / 탐지 / 대응

| 유형 | 악용·문제 시나리오 (예시) | 탐지 신호 | 대응책 | 단계 |
|------|--------------------------|----------|--------|------|
| **승부 담합 (고의 패배)** | 같은 디비전의 A·B 유저가 친구 사이. 시즌 막판 B가 강등 확정되자 A와의 경기에서 골키퍼를 필드 선수로, 전원 체력 20%로 출전시켜 A의 우승을 돕는다 | 평소 대비 급격한 라인업 품질 하락(선발 평균 능력치 z-score), 특정 상대전에서만 발생, 두 계정 간 친구·길드·같은 기기/IP 관계, 결과 확인 없이 플랜만 제출 | 1) 설계: 명백히 비정상 라인업(포지션 불일치 GK 등)은 제출 시 경고 + 자동 보정 2) 탐지 후보 → 운영 검토 3) 확정 시 해당 경기 결과 무효·몰수패 처리, 양측 시즌 보상 회수, 반복 시 정지 | MVP |

| **코치 스파이** | 라이벌 팀 구단주가 부계정으로 상대 팀 코치로 들어가 경기 전날 전술·라인업을 빼낸다 | 코치 계정이 같은 디비전 다른 팀의 구단주/코치와 기기·IP·결제 정보 공유, 코치 가입 직후 전술 화면만 조회, 해당 팀의 상대 팀이 조회 직후 대응 전술 변경 | 1) 설계: 같은 디비전(같은 리그 그룹) 팀 간 코치 겸임 금지 2) 신규 코치는 첫 48시간 "관찰자" 권한(전술 열람은 경기 종료 후만) 3) 구단주가 코치별 열람 로그 확인 가능 4) 확정 시 코치 계정 제재 + 이득 본 팀 조사 | MVP |

| **구단주 계정 공유/탈취** | 구단주가 비밀번호를 코치에게 공유 → 코치가 구단주 권한 사용, 또는 탈취 후 선수 매각 | 새 기기 로그인 + 즉시 고가치 행동, 비정상 지역 로그인 | 중요 행동 시 2단계 인증, 새 기기 로그인 후 24시간 고가치 행동 지연, 구단주 위임 기능을 공식 제공해 공유 동기 제거 | MVP(기본)/1차(2FA) |

| **엔진 익스플로잇** | 특정 슬라이더 조합(예: 수비 라인 최저 + 템포 최대)이 엔진 버그로 비정상 승률 | 특정 설정 조합의 기대 대비 과도한 승률, 커뮤니티 제보 | 긴급 핫픽스는 시즌 중에도 허용(사전 공지), 악용 기간 결과는 원칙적으로 유지하되 명백한 버그 악용자는 개별 검토, 버그 제보 보상 | MVP |
| **매크로/봇** | 스크립트로 여러 팀 플랜 자동 제출, 이적시장 매물 초단위 스나이핑, 보상 수집 자동화 | 인간 불가능한 반응 속도, 일정한 요청 간격, 비공식 클라이언트/API 호출, 한 기기 다수 계정 | 서버 측 요청 빈도 제한, 클라이언트 무결성 검사, 이적시장은 즉시 구매 대신 **짧은 입찰 창(예: 10분) 방식**으로 속도 이점 제거(경제 담당 협의), 단계적 제재 | MVP(레이트 리밋)/1차(무결성) |

| **난수(운) 불만** | "슈팅 20 대 3인데 졌다", "조작 아니냐" | VOC 키워드, 경기 후 1분 내 이탈, 리포트 화면 체류 | 1) 설계: 결과 분산 목표 범위 명시(12.5 H2), 한 경기 운은 크게·시즌 전체 운은 작게(30경기 누적 시 실력 수렴) 2) 경기 리포트에 xG·찬스 품질 표시로 "운이었음"을 설명 3) 시드 기반 결정론 처리로 운영 재현 가능, 요청 시 검증 4) 시즌 누적 "기대 승점 vs 실제 승점" 표시 | MVP |

| **상대 정보 비대칭** | 한쪽은 상대 플랜을 보고 마지막에 카운터 전술로 바꾸고, 다른 쪽은 미리 제출 후 접속 못함 | - (설계 문제) | 상대의 **당일 플랜은 비공개**, 공개 정보는 과거 경기 기록만. 마지막 순간 변경의 이점을 줄이기 위해 조건부 지시와 상대 성향 대응 옵션("상대가 고압박이면 롱볼") 제공 | MVP |
| **리그 배정 조작(스머핑)** | 상위 유저가 새 계정으로 입문 리그에 들어가 신규 유저를 학살 | 신규 계정의 비정상적 전술 숙련도(첫 경기부터 최적 설정), 입문 리그 압도적 득실차 | 입문 리그 성적 극단적 상위 팀은 **시즌 중 조기 승격**, 기기·결제 정보 연계 계정 판별, 입문 리그 보상 상한 | 1차 |
| **팀 내 괴롭힘·분쟁** | 구단주가 코치를 모욕, 코치끼리 채팅 분쟁 | 신고, 금칙어 필터 | 신고·차단·코치 탈퇴 즉시 가능, 탈퇴 코치는 불이익 없음, 반복 신고 구단주는 코치 초대 제한 | MVP |
