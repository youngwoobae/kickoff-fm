## 확인했고 문제 없음 (근거만)

- **세이브 쓰기 순서**: 로그 먼저 → 본문+메타 한 IndexedDB 트랜잭션(원자적, 메타 = 커밋 표식). 압축은 트랜잭션 밖에서 먼저(`await` 로 트랜잭션이 닫히지 않음). 로그가 본문보다 앞서도 읽기는 로그를 쓰므로 무해.
- **구버전 읽기**: 문자열 본문(M7.2 이전)은 그대로 읽힌다(`savePack72.test`). localStorage → IndexedDB 이전은 쓰기 성공 뒤에만 원본 삭제.
- **SW 업데이트 중 저장**: 자동 교체 없음(`skipWaiting` 은 사용자 버튼 → `flush` 성공 뒤에만). 실패하면 교체하지 않는다. 캐시는 같은 오리진 GET 만, 프리캐시 목록은 빌드 산출물로 한정.
- **XSS**: `innerHTML`·`dangerouslySetInnerHTML`·`insertAdjacentHTML`·`eval` 사용처 0. 멤버 이름·사유·메모는 React 텍스트 노드로만 그린다.
- **권한**: 변경 메서드는 `guard`/`ownerOnly`/`ownerManage`/`proposer` 를 먼저 부른다. 딜 승인은 구단주 명의로 `placeBid`·`offerRenewal` 을 다시 실행해 창·잔액·재계약 성립을 재검증(실패 = STALE). `switchRole` 도 `switchMember` 를 거쳐 PIN 을 우회하지 못한다.
- **결정성·캐시**: `tacticEdgeTotal` 캐시 키는 계산에 쓰이는 입력 전부(포메이션·지시·역할 × 2)이고 순수 함수라 무효화가 필요 없다. `pickLineup` 점수 표·`aiBids` 메모·`strengthWith` 는 원래 식과 같은 값(합 순서까지 동일). 골든 시드 테스트·`sim:career --strict` 통과.
- **누수**: `PitchView` rAF·`Tour` rAF/MutationObserver/스크롤·리사이즈·키 리스너·`Sheet` 키 리스너·`prefs` matchMedia·`useSessionLog` 리스너 모두 정리 함수가 있다. `UpdateBanner` 의 문서 리스너는 모듈 1회 등록.
