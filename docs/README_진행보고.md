## 1. 한눈에 보기

**서버·로그인 없이 기기에 설치해 끝까지 하는 축구 감독 게임(오프라인 PWA).** T5 루키 리그에서 시작해 매일 플랜 제출 → "다음 날로 넘기기" → 리포트를 반복하며 T1 우승을 노린다. 데이터는 기기 IndexedDB에만 저장. 런타임 의존성은 `react`·`react-dom`뿐.

| 영역 | 기능 |
|---|---|
| 엔진 | 결정적 시드 엔진, 전술 스타일 9·역할 28·포메이션 9, 상성·조건부 지시, 승부 요인 리포트 |
| 경기 보기 | 텍스트 중계, 2D 탑뷰 중계(모션 줄이기 시 정지 화면) |
| 커리어 | 70구단 5티어 실제 승강(T1~T3 경계 2팀, 아래 경계 3팀), 다른 리그 경량 시뮬, 커리어 기록 |
| 선수 | 성장·노화·은퇴, 훈련 포커스 6종, 유스(시즌당 최대 2명), 경고 5장 누적 정지 |
| 경영 | 이적 창 2개·블라인드 입찰·판매, 재계약·방출·긴급 FA, 5티어 경제, 받은 편지함 |
| 협동 | 한 기기 핫시트: 구단주 1 + 코치 5, 역할별 제안 → 구단주 승인, 구단주 PIN |
| 저장 | 슬롯 3개, 매일 자동 저장(gzip), 파일 내보내기/가져오기, Phase 0 세이브 자동 변환, 여러 창 동시 열기 보호 |
| 앱 | 튜토리얼 6단계, 설정(테마·글자·모션·중계 속도), 서비스 워커 오프라인·업데이트 배너, 접근성 AA 점검 |

## 3. 명령

Node 20.19 이상.

```bash
npm install && npm run dev                              # 개발 (휴대폰: npm run dev -- --host)
npm run typecheck | npm test | npm run build | npm run preview
npm run sim:batch -- --n 2000 --strict                  # 엔진 게이트 (약 9분)
npm run sim:career -- --seeds 20 --seasons 10 --strict  # 커리어 게이트
node --expose-gc --import tsx scripts/perf-bench.ts --seed 1 --seasons 10   # 성능
```

UI만 볼 때 `?fake=1`. 프로덕션 빌드에는 개발자 패널·fake 없음. 옵션: `docs/시뮬레이션_검증.md` 8장, `scripts/sim-career.ts` 머리 주석.
